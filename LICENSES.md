# Licensing status

**No final public source-code licence has been approved or applied to this
repository yet.** Its current private visibility does not grant permission to
copy, redistribute, commercially exploit or publish the contents.

## Proposed Developer Kit licence

Apache License 2.0 is the proposed licence for independently usable public
contracts, SDKs, developer tools, examples and conformance code. Applying it
requires explicit approval by the authorised ANWOR rights holder and a final
copyright and dependency review.

Until that approval is recorded, these components are `licence pending` and
Cargo/Dart publishing remains disabled.

## Proprietary components

Ivy Core and Core UI remain proprietary. No Core or Core UI source licence is
offered here.

## Official system modules

Bridge, Vault, Flow, Hooman and other official system modules are intended to be
covered by a separate ANWOR System Module License. That licence has not been
finalised. Their full source is not present.

## ANWOR community modules

A separate ANWOR Community Module License is planned. It is expected to permit
private modification while requiring separate permission for commercial
exploitation of ANWOR code. This is policy intent only, not approved legal text.

## External modules

External authors retain ownership of their original module code and choose
their own licence, subject to applicable law and third-party rights. Marketplace
admission does not transfer ownership and applies only to the exact reviewed
module version and package identity.

## Dependencies

The Rust prototype currently uses permissively licensed ecosystem dependencies.
The exact transitive dependency set must be regenerated and reviewed before
public launch. CI includes dependency inventory and advisories; it does not
replace legal review.
