# Governance

[Nederlands](../../nl/community/governance.md) | **English**

## Who decides for Ivy Public?

Anyone can propose contributions; official changes need appropriate review. **ANWOR retains final responsibility** for architecture and releases. A *core maintainer* of this public Developer Kit does not automatically gain access to private Ivy Core or ANWOR systems; GitHub access is granted separately.

<!-- section: stewardship -->
## Stewardship

Ivy is currently maintained under ANWOR stewardship. Architectural authority
remains explicit while public contribution paths are being established.

<!-- section: decisions -->
## Decision classes

Documentation, tests and examples use normal pull requests. SDK changes require
an issue and maintainer review. Capability, trust, authority, compatibility,
package or Marketplace changes require an RFC. Official release and protected
module decisions remain with authorised ANWOR maintainers.

<!-- section: review -->
## Review

The author does not self-approve architectural or security-sensitive work.
Review uses the exact commit and checks failure behavior, documentation parity,
licence origin and security scope.

<!-- section: roles -->
## Roles

The intended progression is contributor, regular contributor, area maintainer
and core maintainer. Appointment depends on sustained reviewable work and trusted
judgement, not a single PR.

<!-- section: rewards -->
## Rewards

Recognition or payment is optional and separately agreed. No role or accepted
contribution creates an automatic claim.
