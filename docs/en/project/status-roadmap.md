# Status and roadmap

[Nederlands](../../nl/project/status-roadmap.md) | **English**

## What can I use already?

This page separates **privately developed**, **publicly experimental**, **planned** and **exploratory** work. This prevents an idea or internal implementation from being mistaken for an available public feature. The roadmap promises no release dates.

<!-- section: implemented -->
## Implemented privately

The private pre-1.0 platform contains Core, Core UI, Prism, Bridge, Vault,
Hooman, Flow, Pulse, Kairo, BookMe, SDKs, signed local packages and extensive
failure-oriented tests. This is evidence of development, not a public supported
release.

<!-- section: experimental -->
## Experimental publicly

This repository implements the independent Developer Kit, canonical manifest
subset, schema/semantic fixtures, static-declaration simulator, exact grants,
development signing, widget preview and `hello-clock`.

<!-- section: planned -->
## Planned

Stable runtime bindings, public packaging, official provenance, installation,
updates, rollback, backup, reference modules and Marketplace.

<!-- section: exploring -->
## Exploring

Federation, offline store-and-forward, mobility, maps, optimisation, AI,
manufacturing and public-data integrations.

<!-- section: roadmap -->
## Sequence

Now: publication controls, docs parity and public contract quality. Next:
runtime bindings, package conformance and a reviewed reference module. Later:
distribution, end-user onboarding, catalogue, backup and federation. There are
no public date promises.

<!-- section: claims -->
## Not claimed

Production readiness, stable 1.0 compatibility, complete open source, public
Core, module certification, end-user support or simulator equivalence to Core.
