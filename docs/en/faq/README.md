# Frequently asked questions

[Nederlands](../../nl/faq/README.md) | **English**

<!-- section: availability -->
## Can I install Ivy today?

Not as a supported end-user product. This repository is a private launch
candidate for an experimental Developer Kit. The production runtime and simple
module installation are not public yet.

<!-- section: core -->
## Is this repository Ivy Core?

No. Core and Core UI remain proprietary. The simulator demonstrates selected
contracts, but it is not a security boundary or a replacement for Core.

<!-- section: modules -->
## Can independent developers own and sell modules?

Yes, when they own the necessary rights. A module may be free, commercial,
proprietary or open source. Marketplace admission and any `ANWOR Verified`
label require a separate review of the exact version.

<!-- section: cloud -->
## Does local-first forbid cloud services?

No. Local operation and local data are the normal path. Network services can
participate through explicit, controlled modules and Bridge boundaries.

<!-- section: security -->
## Does a green repository scan make publication safe?

No. Automation reduces risk but cannot establish ownership, legal permission,
absence of contextual personal data, or correctness of every public claim. An
exact-commit human review is mandatory before publication.

<!-- section: licensing -->
## What licence applies?

No repository-wide licence has been approved. Apache-2.0 for the Developer Kit
is only proposed. Core/Core UI remain proprietary and other module classes have
open licence decisions. Do not assume unlicensed files are reusable.
