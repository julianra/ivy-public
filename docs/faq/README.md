# Frequently asked questions

## Is Ivy production ready?

No. Ivy is pre-1.0 and the public Developer Kit is experimental.

## Is all of Ivy open source?

No. Core and Core UI are proprietary. Official module licences are still under
review. The Developer Kit is proposed for Apache-2.0 but is not licensed yet.

## Can I sell my own Ivy module?

The intended policy lets external authors choose their own licence and business
model for original code. Official Marketplace listing requires version-specific
review. Final marketplace terms still need approval.

## Is the simulator a replacement for Core?

No. It is an in-process test harness for declarations, ownership, grants and
revocation. It provides no production isolation, identity, lifecycle or audit.

## Can I run Ivy as a normal user today?

Not through this repository. The private platform has working components, but a
supported simple installer, updates, backup and public releases are planned.
