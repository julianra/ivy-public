# What is Ivy?

Ivy is a platform for composing local capabilities without giving every module
authority over the whole system. The user chooses installed providers and
explicit grants. Modules remain focused on their own domain.

Ivy is useful when software needs to stay private, work locally, survive provider
replacement and integrate multiple domains without collapsing them into a
single application.

Today Ivy is aimed at developers and technical evaluators. End-user installation
and support are planned work.
