# Veelgestelde vragen

**Nederlands** | [English](../../en/faq/README.md)

<!-- section: availability -->
## Kan ik Ivy vandaag installeren?

Niet als ondersteund eindgebruikersproduct. Deze repository is een private
lanceringskandidaat voor een experimentele Developer Kit. De productieruntime
en eenvoudige module-installatie zijn nog niet publiek.

<!-- section: core -->
## Is deze repository Ivy Core?

Nee. Core en Core UI blijven proprietary. De simulator demonstreert gekozen
contracten, maar is geen securitygrens of vervanging voor Core.

<!-- section: modules -->
## Kunnen onafhankelijke ontwikkelaars modules bezitten en verkopen?

Ja, wanneer zij de nodige rechten bezitten. Een module mag gratis, commercieel,
proprietary of open source zijn. Marketplace-opname en elk label
`ANWOR Verified` vereisen een afzonderlijke review van de exacte versie.

<!-- section: cloud -->
## Verbiedt local-first clouddiensten?

Nee. Lokale werking en lokale data zijn het normale pad. Netwerkdiensten kunnen
deelnemen via expliciete, gecontroleerde modules en Bridge-grenzen.

<!-- section: security -->
## Maakt een groene repositoryscan publicatie veilig?

Nee. Automatisering verlaagt risico maar bewijst geen eigendom, juridische
toestemming, afwezigheid van contextuele persoonsgegevens of juistheid van elke
publieke claim. Een menselijke review van de exacte commit blijft verplicht.

<!-- section: licensing -->
## Welke licentie geldt?

De Developer Kit in deze repository valt onder Apache-2.0. Bijdragen gebruiken
DCO 1.1; er is geen CLA. Core/Core UI blijven proprietary en ontbreken hier.
Afzonderlijke moduleklassen kunnen andere licenties gebruiken. Ivy/ANWOR-
trademarks en badges vallen niet onder de Apache-2.0-grant.
