# Support

This is an experimental Developer Kit and has no production support guarantee.

After public launch:

- use Discussions Q&A for development questions;
- use issues for reproducible Developer Kit bugs;
- use RFC Discussions for authority or contract proposals;
- never use public channels for vulnerabilities;
- contact the module author for third-party module support.

ANWOR Official and ANWOR Verified describe provenance or review status; they do
not automatically imply a specific support contract.
