# Governance

Ivy is currently maintained under ANWOR stewardship.

## Decision classes

- Documentation, tests and examples use ordinary pull requests.
- SDK behavior and public tooling changes require an issue and maintainer review.
- Capability, authority, trust, package or compatibility changes require an RFC.
- Security-sensitive and official-module release decisions remain with the
  authorised ANWOR maintainers.

## Review

No contributor approves their own architectural or security-sensitive change.
Pull requests should identify the exact contract and failure behavior affected.
Required checks must pass on the proposed commit.

## Contributor progression

The intended progression is contributor, regular contributor, area maintainer
and core maintainer. Appointments are based on sustained, reviewable work and
trusted judgement. This document does not promise compensation or maintainer
status for any contribution.

## Rewards and recognition

ANWOR may choose to recognise accepted contributions with attribution, credits,
money or other rewards. There is no automatic entitlement. Any paid work or
reward must be agreed separately in writing.
