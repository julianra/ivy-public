# Public roadmap

This roadmap communicates direction, not release promises or dates. Internal
work packets and historical trackers are deliberately excluded.

## Now

- review and approve the Developer Kit licence;
- independently reproduce all Rust and Dart checks;
- review the public manifest subset against private Core behavior;
- improve module author documentation;
- publish sanitized diagrams and real screenshots after privacy review;
- define the public API change policy;
- prepare initial issues and RFC templates.

## Next

- reproducible protobuf generation for public Rust and Dart types;
- development event and widget conformance fixtures;
- package-layout validator without official signing authority;
- richer fake broker with deterministic failure injection;
- first reviewed reference module, probably in a broadly understandable domain;
- version-specific `ANWOR Verified` metadata design;
- module catalogue prototype.

## Later

- coherent installation and onboarding;
- signed downloads and updates with rollback and repair;
- backup, restore and migration;
- online and offline module catalogues;
- appliance, VM, NAS and offline deployment paths;
- public compatibility guarantees approaching 1.0.

## Exploring

- federation and offline store-and-forward;
- navigation and mobility;
- provider-neutral planning and optimisation;
- weather, AI, automotive and manufacturing capabilities;
- public-data integrations.
