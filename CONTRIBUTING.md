# Contributing

- [English contribution guide](docs/en/community/contributing.md)
- [Nederlandse bijdragehandleiding](docs/nl/community/contributing.md)

Public documentation changes must update both language counterparts. No
Contributor License Agreement is used. Every commit must certify the
[Developer Certificate of Origin 1.1](DCO) with:

```bash
git commit -s -m "Describe the change"
```

Contributions accepted into this Developer Kit are licensed under
[Apache-2.0](LICENSE).
